## Show HN

**Title:** Show HN: A book outliner where the share link is the data (100% client-side)

**Body:**
> BookForge Pro turns a paragraph about your book into a structured blueprint
> (logline, acts, chapter beats, blurb). The engine is plain deterministic JS,
> so the same input always gives the same output. Share links encode only the
> input in the URL fragment, which the browser never sends to the server, and
> the recipient rebuilds the blueprint locally.
> There's no backend, no account, and no tracking cookies.
>
> It's MIT licensed. The engine and its tests run in Node with zero dependencies.
> Feedback on the extraction heuristics is very welcome.
